# Robotics & Intelligent Systems Organization 🤖🚀

Bienvenido a la organización **Robotics & Intelligent Systems**. Desarrollamos ecosistemas de simulación de alta fidelidad, herramientas de control industrial, motores de inteligencia artificial y plataformas empresariales impulsadas por el meta-lenguaje **RascalMPL**, **Modelica (GraalVM)** y tecnologías de simulación avanzada.

---

## 🌟 Plataforma y Ecosistema de Repositorios `jfx`

## 🛠️ Requisitos de Entorno y Compilación

Para compilar y ejecutar los componentes de la suite `jfx`:

1. **GraalVM JDK 21+** con soporte para Truffle y ejecución políglota.
2. **RascalMPL CLI / REPL** para la compilación de motores de gestión.
3. **Modelica / JModelica Compiler** para librerías de energía, clima y física.

```bash
# Ejemplo: Clonar y construir un sistema basado en RascalMPL / GraalVM
git clone [https://github.com/robotics-intelligent-systems/jfxfmis.git](https://github.com/robotics-intelligent-systems/jfxfmis.git)
cd jfxfmis
rascal-shell build
